# Wedding Invitation

A mobile-first, single-page wedding invitation. Deploy this directory to Vercel as a static site. No build step is required.

## Personalize it

Edit public/index.html to replace the sample names, date, venue, schedule, and map link. Update the matching text in public/invitation.svg so link previews match the invitation.

The floating Share button uses the phone's native share sheet where available and copies the page URL on other browsers. Social preview metadata is included in the page head.
